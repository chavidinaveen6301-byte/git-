# 💰 Finance Analytics Dashboard

## 📖 About the Project

Managing financial transactions becomes challenging as businesses grow. Large volumes of transaction data make it difficult to track performance, understand customer behavior, and identify business 
trends using traditional reports.

To solve this problem, I developed an interactive **Finance Analytics Dashboard** in **Power BI**. The dashboard brings together key financial metrics, customer insights, and transaction 
analysis into a single report, allowing users to explore business performance through dynamic filters and interactive visualizations.

The dashboard helps stakeholders monitor overall financial performance, compare Year-over-Year (YoY) growth, identify top-performing customer segments and states, analyze transaction success rates, 
and understand customer demographics. It also includes drill-through functionality for detailed transaction-level analysis, making it easier to investigate specific business scenarios.

This project demonstrates my ability to clean and transform data, build an efficient data model, create DAX measures, design interactive dashboards, and turn raw data into meaningful business insights.

---

# 🎯 Business Problem

The organization needed a centralized dashboard to answer important business questions, including:

- How is the business performing over time?
- Which customer segments contribute the highest revenue?
- What is the transaction success rate?
- Which states generate the highest transaction value?
- Which transaction types generate the highest fees and taxes?
- How does customer gender influence transaction value?
- How has business performance changed compared to the previous year?

Without an interactive dashboard, answering these questions required manual reporting, making the analysis time-consuming and less efficient.

---

# 🎯 Project Objectives

The main goal of this project was to build a user-friendly dashboard that helps stakeholders:

- Monitor key financial KPIs in real time.
- Track monthly transaction trends.
- Compare successful, failed, and pending transactions.
- Analyze customer segments and demographics.
- Evaluate state-wise financial performance.
- Measure transaction profitability using Amount, Fees, Tax, and Transaction Count.
- Compare Year-over-Year (YoY) business performance.
- Explore transaction-level details using drill-through reports.

--

# 📊 Key Performance Indicators (KPIs)

The dashboard tracks the following KPIs:

- **Total Transaction Amount**
- **Total Transactions**
- **Average Transaction Value**
- **Total Fees**
- **Total Tax**
- **Year-over-Year (YoY) Growth**

# 📊 Business Insights

The dashboard helped uncover several key business insights:

- Analyzed **₹21.67M** in financial transactions across **2K+ records**.
- Identified an **86.02% transaction success rate**, indicating strong operational performance.
- Found that the **Retail customer segment contributed approximately 56% of the total transaction value**, making it the highest revenue-generating customer segment.
- Discovered that **Male customers contributed 52.31% of the total transaction value**, providing valuable customer demographic insights.
- Compared transaction performance across different states to identify top-performing regions.
- Evaluated transaction profitability by analyzing Amount, Fees, Tax, and Transaction Count across different transaction types.
- Monitored monthly trends and Year-over-Year (YoY) growth to understand changes in business performance.
